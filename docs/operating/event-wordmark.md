# VarCamp reference-style wordmark

The organizer's later reference on 11 November 2026 supersedes the earlier pixel-font selection. All six shared logo PNGs now use white uppercase **VARCAMP** in **Russo One**, chosen as a close visual match to the reference's bold squared letters. The supplied magenta flame and MYANMAR 2026 glyph designs are retained. The later alignment refinement slightly reduces the flame and wordmark, centers the subtitle beneath VARCAMP and tightens its line gap. Native image dimensions, transparent backgrounds and map placements remain unchanged.

The unmodified font is `art/source/event-identity/RussoOne-Regular.ttf`, by Jovanny Lemonad. Its full SIL Open Font License 1.1 is retained alongside it in `OFL.txt`; retain both when distributing the source. The font comes from the [official Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/russoone), with SHA-256 `bc0abcc660bd8b7ad3000ecb2898a27c58a29a50f7ec81652fa12e75148d09df`. This identifies the selected font, not a definitive identification of the screenshot's original font.

`tools/art/event-identity.ts` verifies the bundled font before rendering. Sharp rasterizes the lettering at build time, fits it proportionally into the existing arrival/room/booth footprints. Original source files remain byte-exact; the exported flame is proportionally resized and the subtitle glyphs move without being redrawn. The map browser receives PNGs and does not load a font. The previous `pixel-wordmark.json` and original vector wordmark remain as historical sources.

Run `node --import tsx tools/art/event-identity.ts` and `node --import tsx tools/art/plaza-generated.ts` for an intentional re-export. Update the owner/font registries and exact publication receipts after review. Run `tests/wordmark-alignment.test.ts` for visible spacing and centering, and `tests/pixel-wordmark.test.ts` for typography and provenance. Run each file alone under the required 6GB/no-swap limit, then check artwork under the same limit. Preserve live saved WAMs with the existing release procedure. Inspect entrance, info desk and hall branding after reload.
