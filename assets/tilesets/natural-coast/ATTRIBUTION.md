# Natural backshore tiles

Dune tiles combine unchanged source samples from WorkAdventure WA_Exterior.png with original VarCamp sand. WorkAdventure-specific terms are retained in the accompanying license; use this derivative only in WorkAdventure maps. The layout recipe and compiler are original project code.

The animated shoreline atlases use LPC Base Water by Lanea Zimmerman (Sharm) and the Liberated Pixel Cup contributors, plus original sand. They are separately registered as lpc-water, CC-BY-SA 3.0, with the complete upstream AUTHORS and license retained.

Reference: https://github.com/kokoye2007/wa-beach at 92a8045ccfe9ea1addb7d88391b7a2738ee2e905. Composition reference only; no assets copied from the reference.
